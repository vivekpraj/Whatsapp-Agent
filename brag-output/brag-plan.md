# Brag Plan: WhatsApp Personal AI Assistant

## What is this app?
A personal AI that lives inside WhatsApp — send it a link, a reminder, or a question and it handles all three without installing anything new.

## The angle
No new app. No new interface. Your AI is already on WhatsApp.
Three things most people do manually — bookmarking links, setting reminders, Googling questions — now happen in a chat they already have open.

## Hook (first 2-3 seconds)
Black screen. WhatsApp green glow. One line types out:
**"Your AI is already on WhatsApp."**
Settle 1.2s. Hard cut to the chat.

## Key moments (the middle)
- **Link drop**: User sends an Instagram URL → bot replies "Saved to Sheets. Topic: Instagram Reel ✓" — bubble slides in with a soft card sound
- **Reminder**: User types "Remind me at 6pm to call John" → bot: "Reminder set for 06:00 PM: call John ✓" — second bubble appears, clock icon
- **Q&A**: User: "What's the capital of France?" → bot: "Paris." — clean, dry, instant

## Outro / punchline
Product name fades in bold: **WhatsApp AI Assistant**
Tagline below: "Link. Reminder. Anything."
Subtle green pulse on the WhatsApp logo. Hold 2s. Fade.

## User flow worth showing
Entry: send any message from WhatsApp
Key action: bot classifies intent — link → Sheets, reminder → scheduled, question → answered
Result: instant reply, zero friction

## Tone
- Preset: `app-store`
- Creative direction: dead-simple product reveal — clean chat bubbles, minimal chrome, let the three replies do the talking
- Interpretation: Smooth entrances, feature-card pacing, no comedy, no drama — just a clearly useful product doing its thing

## Format: both — landscape 1920×1080 AND vertical 1080×1920
## Duration: 20 seconds

## Visual identity (from the project)
- Background: #0a0a0a (near-black, WhatsApp dark mode)
- Accent: #25D366 (WhatsApp green)
- Text: #FFFFFF
- Chat bubble (user): #005C4B (WhatsApp outgoing green)
- Chat bubble (bot): #1F2C34 (WhatsApp incoming dark)
- Display font: system-ui, -apple-system, sans-serif (WhatsApp native feel)
- Body font: same
- Strongest visual element: WhatsApp-style chat bubbles showing the 3 intents

## Share copy (draft)
Built a WhatsApp AI that saves links to Sheets, fires reminders, and answers questions — no new app, just send a message.

## Audio direction
- Role: warm upbeat bed, feature-card app-store energy
- Music: happy-beats-business-moves-vol-10 (110 BPM, punchy, compact)
- Music treatment: start at 0s, volume 0.32, fade to 0 over last 1.5s
- Music cue guidance: strong cues cluster at 15.82s and 18.01s — target the outro reveal near 18.01s; beat grid (~0.55s interval) for the 3 chat bubble arrivals
- Audio-reactive treatment: subtle; WhatsApp green accent glow on the hook line breathes with RMS; bot reply tick mark gets a soft presence pulse on bass
- SFX posture: sparse, app-store clean — drop/card sounds for each bubble arrival, bell for the outro logo
- Audio-coupled moments:
  - Hook typing animation — subtle key tick (or drop_001 for each word fade-in)
  - Each chat bubble arrival — card-place-1.ogg or drop_001.ogg (one per bubble, staggered on beat grid)
  - Bot reply ✓ checkmark appearance — click_001.ogg very softly
  - Outro logo/name settle — impactBell_heavy_000.ogg at 0.45 volume
- Restraint rule: no stacking sounds, no glitch, no punch — this is a polished product reveal

## Storyboard
